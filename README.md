# A Thousand Stories

> 1,000 lives. 1,000 journeys. All real.

A factual storytelling platform featuring 1,000 real stories of real people from around the world. No fiction. No fabricated stories. Only real stories supported by factual sources.

## Quickstart

```bash
npm install
ng serve
```

Open [http://localhost:4200](http://localhost:4200)

## Commands

| Command | Description |
| --- | --- |
| `npm install` | Install dependencies |
| `ng serve` | Dev server |
| `ng test` | Run unit tests |
| `ng lint` | Run linter |
| `ng build --configuration production` | Production build |
